# dice-lib Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract words' `src/shared/dice/` into a standalone `~/Projects/dice-lib/` repo consumed by both words and sidequest-ui via local `file:` dependency.

**Architecture:** Lib ships TypeScript source (no `dist/`); binary assets live inside `src/assets/` and are imported via Vite's `?url` mechanism, then re-exported as a `DICE_ASSETS` constants map. Each consumer's Vite bundler emits the assets at build time. Words keeps its `<dice-tray>` web-component wrapper; sidequest keeps `DiceOverlay`/`InlineDiceTray`/`DiceSpikePage`. Words' newer code (FBX pip d6, N-die generalization, snap-upright, d8, dice notation, `DIE_REGISTRY`) is canonical.

**Tech Stack:** TypeScript, React 19, Three.js 0.183, `@react-three/fiber` 9, `@react-three/drei` 10, `@react-three/rapier` 2, `three-stdlib`, Vitest 4.

export interface DiceTheme {
  /** Die body color */
  dieColor: string;
  /** Face number color */
  labelColor: string;
  /** Font URL for face numbers (.ttf only — troika doesn't support .woff2) */
  labelFont?: string;
  /** Surface roughness (0 = glossy, 1 = matte) */
  roughness?: number;
  /** Metalness (0 = plastic, 1 = chrome) */
  metalness?: number;
  /** Normal map URL for surface detail (scratches, pitting, wear) */
  normalMap?: string;
  /** Normal map intensity (default 1.0) */
  normalScale?: number;
  /** Color-map texture URL used by the d6 FBX mesh (baked die body + pips). */
  d6ColorMap?: string;
}

export const DEFAULT_DICE_THEME: DiceTheme = {
  dieColor: "#e8e0d0", // ivory
  labelColor: "#1a1a1a", // near-black
  roughness: 0.3,
  metalness: 0.1,
  normalMap: DICE_ASSETS.scratchedPlasticNormal,
  normalScale: 0.15,
  d6ColorMap: DICE_ASSETS.d6Ivory,
};

export const OBSIDIAN_DICE_THEME: DiceTheme = {

};

export const THEME_PRESETS: Record<string, DiceTheme> = {
