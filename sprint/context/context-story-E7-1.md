## Problem
First Clue playtest: the SVG board reads very plain. Experiment with filling each room polygon with its room portrait (public/shared/portraits/<roomId>.png — all 9 exist: kitchen, ballroom, conservatory, diningroom, billiardroom, library, lounge, hall, study) as a clipped background, behind the room label and pawn/weapon tokens. Board renders room polygons in src/clients/clue/Board.tsx (ROOMS_GEO); room fill is #clue-root .clue-room in plugins/clue/client/style.css. Likely approach: SVG <pattern>/<image> clipped to each polygon, dimmed with a scrim so labels/tokens stay legible. OPEN QUESTION this spike answers: do photoreal room backgrounds work at board scale, or does the board want a purpose-drawn illustrated top-down view instead? Build the image version, screenshot it, and decide keep / revert / go-top-down. Mind the two-stylesheet trap: #clue-root style.css is checked-in high-specificity, the built app.css loses the cascade.
