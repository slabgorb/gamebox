## Problem
src/server/plugin-clients.js:59 runs `SELECT persona_id FROM ai_sessions WHERE game_id = ?`
with a bare `.get()`, so in a multi-bot game it grabs whichever row sqlite returns first.
Only consumed by the 2P opponent-card overlay (gated `d === 2` in Risk), so harmless for the
shipped path, but it's a 2P-shaped assumption in an N-bot world. Make the persona lookup
seat/bot-scoped (resolve the persona for the specific opponent seat being rendered).
